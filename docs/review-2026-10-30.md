# 独立レビューの指摘と対処（2026-10-30）

実装の文脈を持たない新規サブエージェントが、正しさ・設計・UX・保守性の観点でレビューした結果と、その対処。

| 分類 | # | 指摘 | 対処 |
| --- | --- | --- | --- |
| must | M1 | シートを消してから書くため、書き込み失敗（セル50,000字超など）で一覧が空になり、毎回失敗し続ける | 対処済み：上書き→余りを削除の順に。各セルを上限で切り詰め、error に理由を記録 |
| must | M2 | 閲覧者全員が Drive 全体の読み書き権限をスクリプトに渡す。スプシ編集者がコードを書き換えると閲覧者の権限で走る | 対処済み：`appsscript.json` でスコープを `drive.readonly` 等に絞る。編集者を少数に限る旨を文書化。**4ファイル目が増えるので要判断（HANDOFF.md）** |
| should | S1 | fingerprint にファイルIDが無く、入れ直したファイルのリンクが古いまま | 対処済み |
| should | S2 | 閲覧者が「今すぐ同期」を押すと数分後に権限エラー | 対処済み：最初に書き込みを試す。canSync でボタンを無効化 |
| should | S3 | フォルダ一覧が欠けると行を大量削除 | 対処済み：0件、または10行以上で半数超の削除は見送り |
| should | S4 | `-` `=` で始まる note がシートで数式扱いされるおそれ | **実機確認に回す**（HANDOFF.md） |
| should | S5 | 再同期の結果が見えなくなる。要対応の作品を個別に再同期できない | 対処済み：要対応の各行に再同期、結果は同期ラベルに |
| should | S6 | 描き直しでフォーカスを失う、読み上げが繰り返される | 対処済み |
| should | S7 | Drive サムネイルが iframe で読めないとき、描き直しのたびにちらつく | 対処済み：失敗URLを記憶。表示可否そのものは実機確認 |
| should | S8 | 状態の選択肢が5か所以上に散在 | 対処済み：サーバーから渡す。残る箇所は Code.gs のコメントと DEVELOPMENT.md に一覧 |
| should | S9 | Drive の Web 画面ではフォルダのコピーも .json の編集もできない | 対処済み：パソコン版前提を明記し、Web だけの手順を補足 |
| should | S10 | 視点移動のアニメーション途中でサムネイルを撮るおそれ | 対処済み：`isSmoothTransition = False` |
| should | S11 | 同名の手作りフォルダを「書き出し済み」と誤認 | 対処済み：note の「Fusion元」一致で判定、別作品なら `-v2` |
| should | S12 | 出力先の既定がマイドライブ | 対処済み：共有ドライブの例に。プレースホルダのままなら止まる |
| could | — | 一時エラーで resyncItem が行を消す／続きトリガーのロック競合／tags のカンマ割れ／権限エラー判定が広すぎる／NUL 区切り／getGalleryData の英語エラー／aria-current／写真を開けない／再同期の二重押し／画像拡張子の不一致／`*.tmp`／CSV セル内改行／STL 名／未保存ドキュメント | すべて対処済み |
| could | — | `setup` などが `google.script.run` から呼べる | 見送り：`_` 付きにするとトリガー・メニューから呼べる保証がない。害は小さい旨をコメントに明記 |
| could | — | `export_log.csv` が items/ 直下に置かれる | 見送り：同期はフォルダしか読まないので害はない |
