# 3Dプリント作品ギャラリー

**この文書は誰向けか**：研究室の全員（まず最初に読む文書）。何のための仕組みか、何がどこにあるか、ギャラリーの開き方、作品の足し方の概要をつかむためのものです。

---

## 何のための仕組みか

研究室でこれまでに3Dプリンターで作ったものを、後輩が次の3つに**自力で**答えられる形でDriveに残します。卒業した人も、あとから作品を置いていけます。

| 後輩のニーズ | 見られるもの |
| --- | --- |
| これ何？ | 写真、用途、状態（使用中・参考・引退）、備考 |
| また刷りたい | STL / 3MF（印刷用データ） |
| ちょっと変えたい | f3d（Fusionの元データ）、STEP（Fusion以外のCADでも開ける控え） |

## 全体の流れ

```
 作品を入れる                    正                 写し（壊れても作り直せる）
 ┌────────────────────┐
 │ 手で置く           │     ┌───────────┐   同期   ┌──────────┐  表示  ┌────────────┐
 │ Fusionスクリプトで │ ──▶ │  items/   │ ───────▶ │  スプシ  │ ─────▶ │ ギャラリー │
 │ 書き出す           │     │ 作品フォルダ│          │ (index)  │        │ (Webアプリ)│
 └────────────────────┘     └───────────┘          └──────────┘        └────────────┘
```

- **正（唯一の元データ）は `items/` の作品フォルダ**です。1作品＝1フォルダで、説明は中の `meta.json` に書きます。
- スプシとギャラリーは、`items/` から**自動で作られる写し**です。壊れても `items/` から作り直せます。だからスプシは手で編集しません（編集は `meta.json` で）。
- 作品を登録するには、ギャラリーの「作品を追加する」でファイルを上げるか、`items/` に作品フォルダを置きます。どちらも作品フォルダができ、それが正になります。
- 「同期」とは、`items/` を読んでスプシを最新にする処理のことです。毎日自動で走るほか、ボタンでも実行できます（詳しくは [OPERATION.md](OPERATION.md)）。

## どこに何があるか

すべて研究室の**共有ドライブ**の `3Dギャラリー/` にあります（個人のマイドライブに置くと、持ち主の卒業でアカウントごと消えるため）。

```
3Dギャラリー/
├── items/                     ← 作品フォルダを置く場所（これが正）
│   ├── 20250612_流路セルホルダー/
│   │   ├── meta.json          作品の説明（必須）
│   │   ├── thumb.png          一覧に出る画像
│   │   ├── 流路セルホルダー.f3d / .step
│   │   ├── base.stl / lid.stl 印刷用
│   │   └── photo_01.jpg       写真（任意）
│   ├── 20250903_ステージ用スペーサー/
│   └── _template/             ← 先頭が _ のフォルダは同期されない。コピーして使う雛形
├── index（スプシ）             ← 同期の結果。GASのコードもここに入っている
└── tools/                     ← コードの控えと文書
    ├── gas/                   Code.gs, index.html, guide.html, appsscript.json
    ├── fusion_export/         Fusion書き出しスクリプト
    └── docs/                  この文書たち
```

作品フォルダの正確なルール（フォルダ名、必要なファイル、`meta.json` の書き方）は [DEVELOPMENT.md の「データ仕様」](DEVELOPMENT.md#データ仕様) が正です。ギャラリーの「作品を追加する」にも同じ内容が図入りで載っています。

### 初めて開くとGoogleの許可画面が出ます

初回は「このアプリがGoogleアカウントのデータへのアクセスを求めています」のような**許可画面**が出ます。これは正常です。

- このギャラリーは、開いた人自身の権限で動きます（Webアプリが「アクセスしているユーザー」として実行される設定）。そのため、スプシと、同期のときの `items/` の読み取りに、あなたのアカウントの許可が必要になります。
- 求められる許可は、**Googleドライブ**（画面から作品を登録・編集するときに、`items/` の作品フォルダへ書き込むため）と、スプレッドシートの操作などです。研究室で作ったアプリなので、**許可して大丈夫です**。ギャラリーが書き込むのは、あなたが「登録する」「保存する」「ゴミ箱に移す」を押したときの、`items/` の中だけです。
- コードは `tools/gas/` にあり、誰でも中身を確認できます。データを外部に送る処理はありません。ギャラリーを見るだけなら何も書き換わりません（「今すぐ同期」・登録・編集はスプシにも書き込むので、スプシの編集権限がある人だけに出ます）。
- 許可は1回で済みます。「このアプリは確認されていません」と出た場合は「詳細」→「（アプリ名）に移動」を選んでください。
- 画面が開かない・画像が出ないときは、共有ドライブ `3Dギャラリー` と、スプシに**閲覧権限**があるか（研究室のメンバーとして追加されているか）を確認してください。

## 作品を足すには（要約）

いちばん簡単なのは、ギャラリー右上の「**作品を追加する**」です。

1. 3Dデータ（f3d・STEP・STL など）と写真を、画面に落とす（「ファイルを選ぶ」でも可）。落とした時点で上がり始めます
2. 複数の作品をまとめて落としたときは、どのファイルがどの作品かを仕分ける（たいていは自動で分かれています。フォルダごと落とすと、フォルダ1つが作品1つ）
3. 作品ごとに、名前・作った日・用途・状態・タグ・メモ・作った人を書く（既にあるタグや名前は候補から選べます）
4. 「確かめる」→「登録する」。すぐ一覧に出ます（同期は要りません）

1ファイル 20MB を超えるものは画面から上げられないので、登録したあと、ドライブでその作品のフォルダに入れてください。登録したあとは、詳細の右上の「**編集**」でタグ・メモ・ファイルを直せます。

ドライブに直接置く方法と、Fusion からまとめて書き出す方法は、「作品を追加する」の右の ▾ から開く「ドライブ・Fusion から追加する」に、用意するもの（1 3Dデータと画像 → 2 `meta.json` → 3 フォルダ）の順に書いてあります。要点だけ書きます。

- **ドライブに直接置く（数件を手で）**：`items/_template/` をコピーして `YYYYMMDD_名前`（日付はモデルの作成日）に改名し、f3d・STEP・STL（または3MF）・`thumb.png` を入れ、`meta.json` の `author` `purpose` `status` を埋めて `items/` に置く。
- **Fusion からまとめて書き出す**：`tools/fusion_export/fusion_export.py` で、Fusionのクラウドにあるf3dを一括で書き出す（手順は [OPERATION.md の「Fusion書き出しの運用」](OPERATION.md#fusion書き出しの運用)）。書き出した `meta.json` の `fusion_id` は消さない・書き換えない（書き出し済みかの判定に使う印）。書き出し直したいときは作品フォルダを消してから再実行する。
- **`meta.json` をAIに頼む**：パネルの「文をコピー」で、ファイルを読み書きできるAIエージェント（Claude Code など）に渡す文をコピーできる。案の表を確かめて返事をすると、`meta.json` を書いてフォルダに並べるところまでやってくれる。
- **`meta.json` を画面で書く**：Fusion から書き出した直後の作品は、説明が空のまま「一覧に出ていない作品」に並びます。各行の「**画面で直す**」から、その場で書けます。
- ドライブに置いたあとは、ギャラリーの「**今すぐ同期**」を押すと一覧に出ます。出ないときは、一覧の上に理由（「一覧に出ていない作品」）が表示されるので、「画面で直す」か `meta.json` を直してもう一度同期してください。
