# 構築手順（SETUP）

**この文書は誰向けか**：ギャラリーを最初に作る人（または作り直す人）。この順に進めれば動くようになります。プログラミングの知識は要りません。所要時間の目安は30〜60分です。

用語を先に説明します。

- **GAS（Google Apps Script）**：Googleのスプレッドシート等に付けられる、小さなプログラムの仕組み。このギャラリーのコードはこれで動きます。
- **コンテナバインド**：スプレッドシートの中に収まっているGASのこと。スプシと一緒に保存され、スプシのメニューからも呼べます。
- **スクリプトプロパティ**：GASのプロジェクトに保存する設定値（名前と値の組）。コードに直接書きたくない値を置きます。
- **トリガー**：「毎日4時台に」のように、決まった時に自動でGASの関数を動かす仕組み。
- **デプロイ**：GASをWebアプリ（URLで開けるページ）として公開すること。

## 全体の手順

1. 共有ドライブとフォルダを用意する
2. `tools/` をドライブに置く、`_template` を `items/` に置く
3. インデックス用スプシを作り、Apps Script を開く
4. 4ファイル（Code.gs, index, guide, appsscript.json）を貼り付ける
5. スクリプトプロパティ `ITEMS_FOLDER_ID` を設定する
6. `setup()` を実行して許可する
7. Webアプリとしてデプロイする
8. 動作確認（テスト用作品を置く）

必要なもの：このリポジトリの `tools/` フォルダ一式、共有ドライブを作れる（または管理者になれる）Googleアカウント。

---

## 1. 共有ドライブと `3Dギャラリー/` フォルダを用意する

1. Googleドライブの左メニュー「共有ドライブ」から、研究室の共有ドライブを開く（無ければ新規作成する）。
   - **マイドライブには置かないでください。** 持ち主のアカウントが卒業で削除されると、フォルダごと消えます。
2. 共有ドライブの中に、フォルダ `3Dギャラリー` を作る。
3. その中に、フォルダ `items` と `tools` を作る。

```
3Dギャラリー/
├── items/
└── tools/
```

4. 共有ドライブに、使う人（研究室メンバー）を追加する。権限の目安：
   - 見るだけの人：閲覧者
   - 作品を足す人：投稿者以上（`items/` に書き込めること）
   - 「今すぐ同期」を押す人：**スプシの編集権限**が必要（`items/` は閲覧できれば足りる）。この研究室では、メンバー全員をスプシの編集者にする方針（[権限の決め方](#権限の決め方安全のために)）
   - 管理者：2人以上にしておく（交代手順は [OPERATION.md](OPERATION.md#管理者交代時の手順)）

## 2. ファイルを置く

1. このリポジトリの `tools/` の**中身**（`gas/`, `fusion_export/`, `docs/`）を、ドライブの `3Dギャラリー/tools/` にアップロードする。コードの控えと文書になります（ここに置いただけではギャラリーは動きません。次の手順で貼り付けます）。
2. `tools/items_template/_template/` フォルダを、`3Dギャラリー/items/` の中にアップロードする。`items/_template/` ができ、中に `meta.json` と `README.txt` があればOKです。先頭が `_` のフォルダは同期されないので、ギャラリーには出ません。

> `dev/`（ローカルでの動作確認用）はドライブに置きません。リポジトリにだけあります。

## 3. インデックス用スプシを作り、Apps Script を開く

1. `3Dギャラリー/` フォルダで「新規 → Google スプレッドシート」を選び、名前を `index` にする（別の名前でも動きます）。シートの中身は空のままでよい。
2. スプシのメニュー「**拡張機能 → Apps Script**」を開く。新しいタブでスクリプトエディタが開きます。これがコンテナバインドのGASプロジェクトです。
3. 左上のプロジェクト名（「無題のプロジェクト」）をクリックして、`3Dギャラリー` などに変えておく。

## 4. 4ファイルを貼り付ける

エディタには最初から `Code.gs` があります。次の3ファイルを、**この名前で**用意します。そのあと、4つ目の `appsscript.json`（設定ファイル）を置き換えます。

| エディタ上のファイル名 | 元のファイル | 作り方 |
| --- | --- | --- |
| `Code.gs` | `tools/gas/Code.gs` | 既存の `Code.gs` の中身を全部消して貼り付ける |
| `index` | `tools/gas/index.html` | 左の「ファイル」の横の「＋」→「HTML」→ 名前に `index` と入力 |
| `guide` | `tools/gas/guide.html` | 同じく「＋」→「HTML」→ 名前に `guide` と入力 |

手順：

1. `Code.gs`：エディタで `Code.gs` を選び、既存の内容（`function myFunction() {}` など）を全部消し、元ファイルの全文を貼り付ける。
2. `index`：「ファイル」の「＋」→「HTML」を選び、名前を `index` にして作る（拡張子 `.html` はエディタが自動で付けるので入力しない）。最初から書かれているタグを全部消して、`index.html` の全文を貼り付ける。
3. `guide`：同様に `guide` を作り、`guide.html` の全文を貼り付ける。
4. 左のファイル一覧が `Code.gs` / `index.html` / `guide.html` の3つ（と、表示をオンにした `appsscript.json`）になっていることを確認する（エディタは HTML に自動で `.html` を表示します）。
5. 保存（Ctrl+S）する。続けて下の `appsscript.json` の設定をする。

### 4つ目：`appsscript.json` を置き換える（許可の範囲を絞る）

`appsscript.json` は、このGASプロジェクトの設定ファイル（マニフェスト）です。ここで「このアプリが求める許可」を絞ります。**これを置かないと、閲覧者の許可画面にDriveの「すべての表示・編集・削除」のような広い許可が出てしまいます。** 置くと「Driveの閲覧のみ」になります。

1. Apps Script エディタ左の歯車「**プロジェクトの設定**」を開く。
2. 「**『appsscript.json』マニフェスト ファイルをエディタで表示する**」をオンにする。
3. 左のファイル一覧に出た `appsscript.json` を開き、中身を全部消して、`tools/gas/appsscript.json` の全文を貼り付けて保存する。

中身の要点（そのまま貼ればよく、通常は触りません）：

| 項目 | 値 | 意味 |
| --- | --- | --- |
| `oauthScopes` | `drive.readonly` / `spreadsheets` / `script.scriptapp` / `script.container.ui` | 求める許可。Drive は閲覧のみ、スプシは読み書き、トリガーの作成、メニューの表示 |
| `webapp.executeAs` | `USER_ACCESSING` | ウェブアプリにアクセスしているユーザーとして実行 |
| `webapp.access` | `DOMAIN` | 同じ組織（大学ドメイン）のアカウントだけが開ける |
| `timeZone` | `Asia/Tokyo` | 毎日の同期の時刻などに効く |

**個人の Gmail（`@gmail.com`）では `"access": "DOMAIN"` が使えません**（組織が無いため）。個人アカウントで1人で試す場合は、`access` を `"MYSELF"`（自分だけ）に書き換えてください（`"ANYONE"` にすると、Googleアカウントを持つ人なら URL を知っていれば誰でも開けます）。本番では大学ドメインのアカウントで運用してください。なお、実際の公開範囲はデプロイ画面の「アクセスできるユーザー」で決まります。
なお、コードに新しい Google サービスを使う改修をしたときは、この `oauthScopes` も直す必要があります（[DEVELOPMENT.md](DEVELOPMENT.md#データ仕様を変えるときに直す箇所)）。

**ファイル名が大事な理由**：`Code.gs` が `index` と `guide` をその名前で読み込みます。名前が違うと「HTML ファイルが見つかりません」と出ます。

## 5. スクリプトプロパティ `ITEMS_FOLDER_ID` を設定する

どのフォルダを同期するかを教える設定です。

1. **フォルダIDを調べる**：ドライブで `3Dギャラリー/items` フォルダを開き、ブラウザのアドレスバーを見る。URL が
   `https://drive.google.com/drive/folders/1AbCdEfGhIjKlMnOpQrStUvWxYz` なら、`folders/` の後ろの `1AbCdEfGhIjKlMnOpQrStUvWxYz` がフォルダIDです（`?` が続く場合はその手前まで）。
2. Apps Script エディタ左の歯車「**プロジェクトの設定**」を開く。
3. 下の方の「**スクリプト プロパティ**」で「スクリプト プロパティを追加」を押す。
4. プロパティに `ITEMS_FOLDER_ID`、値に調べたIDを入力して「スクリプト プロパティを保存」。

`items` フォルダ（`3Dギャラリー` ではありません）のIDであること、前後に空白が入っていないことを確認してください。他のプロパティは自動で作られるので、設定するのはこの1つだけです。

## 6. `setup()` を実行して許可する

`setup()` は初期設定です。シートの見出しの作成、「警告のみ」の保護（手で編集しようとすると警告が出る）、毎日の自動同期のトリガー登録を行います。何度実行しても同じ状態になります（トリガーは重複しません）。

**方法A：エディタから**

1. エディタ上部の関数選択で `setup` を選び、「実行」を押す。
2. 「承認が必要です」と出たら「権限を確認」→ 自分のアカウントを選ぶ。許可の内容は `appsscript.json` で絞った範囲（Driveは閲覧のみ、スプシ、トリガー、メニュー）です。「このアプリは Google で確認されていません」と出たら、「詳細」→「（プロジェクト名）（安全ではないページ）に移動」→「許可」。自分たちで作ったスクリプトなので問題ありません。
3. 実行ログに「items フォルダ：items」「毎日の同期：登録しました（4時台）」などが出れば成功。

**方法B：スプシのメニューから**

1. スプシのタブに戻り、ページを再読み込みする（メニューが追加されるのに数秒かかります）。
2. メニュー「**ギャラリー → 初期設定**」を選ぶ。初回は許可の画面が出るので、方法Aと同じく許可する。
3. 結果がダイアログに出る。

続けて、メニュー「**ギャラリー → 今すぐ同期**」を一度実行しておくと、`items/` の内容がシートに入ります（空でも動作します）。

うまくいかないとき：

| 表示 | 原因 |
| --- | --- |
| スクリプトプロパティ「ITEMS_FOLDER_ID」が設定されていません | 手順5が未実施。プロパティ名の綴り（大文字）も確認 |
| items フォルダ（ID: …）を開けません | IDの誤り、またはそのフォルダを見る権限が無い |

## 7. デプロイ（Webアプリとして公開）する

1. エディタ右上の「**デプロイ → 新しいデプロイ**」を押す。
2. 左の歯車（種類の選択）→「**ウェブアプリ**」を選ぶ。
3. 次のように設定する。

   | 項目 | 設定 |
   | --- | --- |
   | 説明 | 例：初版 |
   | 次のユーザーとして実行 | **ウェブアプリにアクセスしているユーザー**（`appsscript.json` の `USER_ACCESSING`） |
   | アクセスできるユーザー | **研究室の範囲**（大学ドメイン内、または研究室メンバーに限る。「全員」にはしない。`appsscript.json` の `DOMAIN` に対応） |

4. 「デプロイ」を押し、許可を求められたら許可する。
5. 表示される「**ウェブアプリのURL**」（`https://script.google.com/macros/s/…/exec`）をコピーし、[README.md](README.md) の「（ここにURLを書く）」の部分に書く。

「実行ユーザー：アクセスしているユーザー」にする理由：Driveとスプシの閲覧権限がそのまま効き、構築者が卒業しても権限の持ち主が消えないからです。その代わり、見る人は**スプシに閲覧権限**が要り、初回に許可画面が出ます（README に説明があります）。スプシを研究室メンバーに共有しておいてください（共有ドライブ内に置いてあれば、共有ドライブのメンバーに自動で共有されます）。

### 更新するとき：「新しいデプロイ」と「デプロイを管理」の違い

コードを直したあと、公開中のURLに反映するには**「デプロイを管理」から既存のデプロイを更新**します。

| 操作 | 結果 |
| --- | --- |
| デプロイ → **デプロイを管理** → 鉛筆（編集）→ バージョン「**新バージョン**」→ デプロイ | **URLはそのまま**で、中身だけ新しくなる。通常はこちら |
| デプロイ → **新しいデプロイ** | **別のURLが増える**。古いURLは古いコードのまま動き続ける。配ったURLが変わってしまうので、通常は使わない |

コードを貼り替えただけでは公開中のURLには反映されません。必ず「デプロイを管理」で新バージョンを出してください。また、コードを変えたのに「デプロイ → デプロイをテスト」のURLで見ている場合は、テスト用の最新コードが動きます（本番とは別物です）。

### 権限の決め方（安全のために）

**この研究室の方針：メンバー全員をスプシの編集者にする**（2026-10-30 決定）。管理者が誰になるか、権限の設定を保守し続けられるかが分からないため、権限の管理が要らない形を選んだ。全員が「今すぐ同期」を押せる。

この方針で受け入れているリスク：**スプシ（＝スクリプト）の編集者は、コードを書き換えられます。そのコードは、ギャラリーを開いた人の権限で動きます。** つまり、編集者は理屈の上では、ギャラリーを開いた人のDriveを読むコードを置けます。全員が同じ研究室のメンバーなのでこのリスクを受け入れ、被害の範囲は `appsscript.json` で「Driveは閲覧のみ」に絞って抑えています（書き換え・削除はできない）。

- 研究室の外の人（共同研究先など）にギャラリーを見せるときは、その人をスプシの**閲覧者**にする（編集者にしない）。閲覧者には「今すぐ同期」が押せない理由が表示され、毎日の自動同期で最新になる。
- `items/` は**閲覧できれば同期できます**（同期はDriveを読むだけ）。作品を置く人には `items/` への書き込み権限（投稿者以上）が要ります。
- 将来、方針を「編集者は少数」に変える場合は、スプシの共有設定で編集者を絞るだけでよい（コードの変更は不要）。

## 8. 動作確認

テスト用の作品を2〜3件置き、1件はわざと壊して、「要対応」が出るかまで確かめます。

1. `items/_template/` をコピーして、`items/` に次の3つを作る（コピーして改名する。フォルダ名は例）。
   - `20250101_テスト正常A` … `meta.json` を `{"author":"テスト","purpose":"動作確認用","status":"使用中","tags":["テスト"],"note":["確認用です"]}` のように書く（整形は不要）。あれば画像を `thumb.png` として入れる。
   - `20250102_テスト正常B` … `status` を `参考` にして、`note` を配列で2行書く。写真があれば `photo_01.jpg` を入れる。
   - `20250103_テスト壊れ` … **わざと壊す**。`meta.json` の `status` を `使ってる` にする（選択肢外）。
2. スプシのメニュー「ギャラリー → 今すぐ同期」を実行する。同期の前にスプシへ書き込めるかが確かめられ、権限が無いとすぐに「同期にはスプシの編集権限が必要です（items フォルダは閲覧できれば足ります）」と出ます。成功すると画面右下に「同期しました（3件を確認、3件を更新）」のように出る。
3. スプシの `items` シートに3行できていて、`20250103_テスト壊れ` の `error` 列に「`status` は 使用中 / 参考 / 引退 のどれかにしてください…」が入っていることを確認する。
4. ギャラリーのURLを開く（初回は許可画面が出る）。
   - 一覧に正常な2件が出る。
   - 一覧の上に「一覧に出ていない作品が1件あります」と `20250103_テスト壊れ` が表示され、「Driveのフォルダ」「スプシの該当行」のリンクが開く。
   - 作品を選ぶと詳細が出て、ファイルのリンクとダウンロードが動く。
5. 壊れた作品の `meta.json` を直して、要対応の行の「再同期」ボタン（またはギャラリーの「今すぐ同期」）を押す。要対応が消え、3件が出る。
5b. 可能なら、スプシの**閲覧者**のアカウントでもギャラリーを開き、一覧が見えること、「今すぐ同期」ボタンが押せない状態（ホバーで「同期にはスプシの編集権限が必要です」）になっていることを確認する。
6. 確認が終わったら、テスト用の3フォルダをゴミ箱へ移し、もう一度「今すぐ同期」を押す（シートの行も消える）。

画像が出ない場合は、ブラウザの設定（サードパーティCookieのブロック）や権限が原因のことがあります。出ない場合は形のアイコンが代わりに表示されます（動作には支障なし）。
