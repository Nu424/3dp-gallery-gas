このフォルダは作品フォルダの雛形です。名前が _ で始まるので、ギャラリーには出ません。

■ 使い方
1. このフォルダをコピーして、名前を「YYYYMMDD_名前」に変える
   例：20250612_流路セルホルダー
   日付はモデルを作った日（わからなければ大体で）。/ \ : などの記号は使わない
2. Fusionでデザインを開き、ファイル › エクスポートで .f3d と .step を保存する
3. 印刷用に、部品ごとの .stl（または .3mf）を保存する
   （ボディを右クリック →「メッシュとして保存」でもよい）
4. 見栄えのよい角度で画面をキャプチャし、thumb.png として保存する
   使っている様子の写真は photo_〜.jpg という名前で入れる
5. meta.json の author・purpose・status を埋める。書ききれないことは note へ
     author  : 作った人
     purpose : 何のための部品か（一行）
     status  : 使用中 / 参考 / 引退 のどれか
     tags    : 絞り込みに使うことば。例 ["顕微鏡", "治具"]
     note    : そのほか全部。1行ずつ。例 ["M3ネジ×4で固定。", "縦向きで刷る。"]
6. フォルダを items/ に置き、ギャラリーの「今すぐ同期」を押す

この README.txt は消しても残しても構いません（残すとギャラリーのファイル一覧に出るだけです）。
詳しくはギャラリーの「作品を追加する」か、tools/docs/README.md を見てください。
