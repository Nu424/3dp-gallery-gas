共有ドライブの 3Dギャラリー/items/ に作品フォルダを1つ置くと、次の同期で一覧に出ます。数件なら手で、Fusionのクラウドからまとめて出すならスクリプトが速いです。

フォルダの形

フォルダ名は 作成日_名前（例：20250612_流路セルホルダー）。作成日がわからなければ大体でかまいません。中にファイルを並べるだけで、サブフォルダは作りません。

meta.json必須作品の説明。これが無いフォルダは一覧に出ません。書き方は下を参照。
thumb.png / thumb.jpg推奨一覧のカードに出る画像。無ければフォルダ内の最初の画像を代わりに使います。
〜.f3d推奨Fusionの元データ。寸法を変えるなど、形を直すときに使います。
〜.step推奨Fusionが無くても他のCADで開ける控え。形は残りますが、作った手順（履歴）は残りません。
〜.stl / 〜.3mf推奨印刷用。部品ごとに1ファイル（base.stl、lid.stl など）にしておくと、1部品だけ刷り直せます。
photo_〜.jpg / .png任意名前を photo_ で始めると、詳細の写真欄に並びます。取り付けた様子があると伝わりやすいです。
そのほか任意図面のPDFなど。詳細のファイル一覧に出ます。

名前が _ で始まるフォルダ（_template など）は一覧に出ません。

meta.json の書き方

{
  "author": "山田",
  "purpose": "流路セルを顕微鏡ステージに固定する",
  "status": "使用中",
  "tags": ["顕微鏡", "治具"],
  "note": [
    "M3ネジ×4で固定。",
    "縦向きで刷らないと爪が折れる。"
  ]
}
author必須作った人
purpose必須何のための部品か。一覧に出る一行
status必須使用中・参考・引退のどれか
tags任意絞り込みに使うことば
note任意そのほか全部。1行ずつ配列で
fusion_id自動Fusionから書き出すと入る。消さない・書き換えない

つくり方

この手順は、Google ドライブ（パソコン版）でフォルダを開いて作業する前提です。Webの画面だけで進めるときは、新しいフォルダを作り、_template の meta.json をダウンロードして編集し、そのフォルダへアップロードします。同じ名前のファイルがあるときは「置き換える」を選んでください（2つあると要対応になります）。

  1. 1items/_template をコピーして、フォルダ名を「YYYYMMDD_名前」に変える
  2. 2Fusionでデザインを開き、ファイル › エクスポートで .f3d と .step を保存する
  3. 3印刷用に、部品ごとの .stl（または .3mf）を保存する（ボディを右クリック →「メッシュとして保存」でもよい）
  4. 4見栄えのよい角度で画面をキャプチャし、thumb.png として保存する
  5. 5meta.json の author・purpose・status を埋める。書ききれないことは note へ
  6. 6フォルダを items/ に置き、「今すぐ同期」を押す
  1. 1tools/fusion_export/fusion_export.py を、Fusionの「スクリプトとアドイン」に登録する
  2. 2設定欄で対象プロジェクトを指定し、モード1（サムネイルのみ）で実行する。パソコンの「ドキュメント\3Dギャラリー_仕分け」に triage.csv と画像が出る（特定のファイルだけなら TARGET_NAMES に名前を書く）
  3. 3triage.csv をスプシで開き、ランク（A・B・C）とフォルダ名を書き込む
  4. 4設定欄の OUTPUT_DIR を items/ にして、モード2（フル書き出し）で実行する。ここで登録まで終わる
  5. 5各フォルダの meta.json を埋める（下のAI用の文を使うと楽）
  6. 6「今すぐ同期」を押し、一覧の上の「要対応」の表示が消えれば完了

## 仕様
- 1作品＝1フォルダ。フォルダ名は YYYYMMDD_名前（日付はモデルの作成日）
- フォルダ内はサブフォルダを作らずフラットに置く
- 代表画像は thumb.png または thumb.jpg、追加写真は photo_ で始める
- 印刷用STLは部品ごとに分ける（base.stl, lid.stl など）
- meta.json のキーは author, purpose, status, tags, note の5つだけ
  - status は「使用中」「参考」「引退」のいずれか
  - note は文字列の配列（1要素＝1行）
  - 例外: Fusion から書き出したフォルダの meta.json には fusion_id がある。
    これは消さず、値も変えない（書き出し済みの目印）

## 進め方
1. ファイルを見て作品ごとにまとめる。どれが同じ作品か迷ったら聞く
2. 作成日・名前・作者・用途・状態を、全作品分まとめて一度に質問する。
   ファイル名や更新日から推測できるものは案として示す
3. フォルダ名を決めてファイルを配置し、meta.json を書く。仕様外の情報は note へ
4. 最後にフォルダ構成と各 meta.json を一覧で見せて、確認をもらう

## やらないこと
- モデルの形状やファイルの中身の変更
- 仕様にないキーやフォルダの追加

置いたあと

上の「今すぐ同期」を押すと一覧に出ます。出ないときは一覧の上に理由が表示されるので、その作品の meta.json を直してもう一度同期してください。
