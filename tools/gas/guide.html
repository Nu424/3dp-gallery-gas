作品1つ＝共有ドライブの 3Dギャラリー/items/ の中のフォルダ1つです。下の 1〜3 を用意して置き、「今すぐ同期」を押すと一覧に出ます。数件なら「手でやる」、まとめてなら「自動でやる」が楽です。

13Dデータと画像を用意する

〜.f3d推奨Fusionの元データ。寸法を直すときに使う
〜.step推奨Fusionが無くても他のCADで開ける控え
〜.stl / 〜.3mf推奨印刷用。部品ごとに1ファイル（base.stl、lid.stl など）
thumb.png / thumb.jpg推奨一覧のカードの画像。無ければフォルダ内の最初の画像
photo_〜.jpg / .png任意詳細に並ぶ写真。取り付けた様子があると伝わりやすい
そのほか任意図面のPDFなど。詳細のファイル一覧に出る

手でやるFusionから1件ずつ保存する

  1. 1デザインを開き、ファイル › エクスポートで .f3d と .step を保存する
  2. 2部品ごとにボディを右クリック →「メッシュとして保存」で .stl を保存する
  3. 3見栄えのよい角度で画面をキャプチャし、thumb.png として保存する

自動でやるFusionのスクリプトでまとめて書き出す

1〜3 がまとめて済みます（フォルダと、空欄の meta.json もできる）。

  1. 1登録（初回だけ）：共有ドライブの 3Dギャラリー/tools/fusion_export フォルダをパソコンにコピーする。Fusionの ユーティリティ › スクリプトとアドイン（Shift+S）の「＋」から、そのフォルダを選ぶ
  2. 2設定：fusion_export.py をメモ帳などで開き、冒頭の設定欄に書いて保存する。最低限、PROJECT_NAMES（対象のプロジェクト名）と OUTPUT_DIR（items/ の場所。エクスプローラーでそのフォルダを開き、アドレスバーのパスを使う）。パスは r"…" の "" の中に書き、先頭の r は消さない
  3. 3仕分け：MODE = 1 で実行すると、パソコンの「ドキュメント\3Dギャラリー_仕分け」に triage.csv と画像が出る。登録したい行の rank に A（現役）か B（参考）を書き、必要なら folder_name を直す（日付が 00000000 の行は実在の日付に）。実行中は triage.csv を閉じておく
  4. 4書き出し：MODE = 2 で実行すると、items/ に作品フォルダができる。続きは 2 の meta.json を埋めるだけ

特定のファイルだけなら TARGET_NAMES に名前を書く。設定の詳細は tools/docs/OPERATION.md。

手でやるメモ帳で書く

  1. 11 のファイルをまとめたフォルダに items/_template の meta.json をコピーし、メモ帳で開く（スクリプトで書き出したなら、できている meta.json を開く）
  2. 2上の例のように "" の中を埋めて保存する。区切りの , と "" は消さない

自動でやるAIエージェントに頼む

ファイルを読み書きできるAIエージェント（Claude Code など）に、この文と、1 のファイル（またはスクリプトで書き出したフォルダと triage.csv）を渡します。全作品の案が表で出るので、確かめて返事をすると、meta.json を書いてフォルダに並べるところ（3）までやってくれます。

研究室の3Dプリント作品ギャラリーへの登録を手伝ってください。
渡したもの（ファイルやフォルダ、または書き出し済みの作品フォルダと仕分け表 triage.csv）から、
下の仕様どおりの作品フォルダと meta.json を仕上げてください。

## 仕様
- 1作品＝1フォルダ。フォルダ名は YYYYMMDD_名前
  - 日付はモデルの作成日で、実在する日付にする。名前の部分に日付を重ねない
  - 名前は一覧で見て何かわかる日本語にする。内輪の略称は使わない。/ \ : は使わない
- フォルダ内はサブフォルダを作らずフラットに置く
- 代表画像は thumb.png または thumb.jpg、追加の写真は名前を photo_ で始める
- 印刷用の STL は部品ごとに分ける（base.stl, lid.stl など）
- meta.json のキーは author, purpose, status, tags, note の5つだけ
  - author: 作った人。表記は最初に1回だけ確認し、全作品でそろえる
  - purpose: 何のための部品かを一行で。フォルダ名の言い換えで終わらせない
  - status: 「使用中」「参考」「引退」のいずれか
  - tags と note は文字列の配列（note は1要素＝1行）
  - 例外: 書き出し済みの meta.json にある fusion_id は、消さず値も変えない

## タグ
- タグは絞り込みのためにある。増やすより、既存のタグや上位の概念にまとめる
- 付けるのは2種類だけ: 装置・研究テーマ／種類（試作、見本、ケース、ふた など）
- 1作品にしか付かないタグ、部品名そのもの、形の一般名（治具、ホルダー、スタンドなど）は作らない
- items フォルダに既存の作品があれば、先にそのタグを集計して語彙を合わせる
- 新しいタグが要るときは、理由を添えて提案し、確認を取ってから使う

## status
- 「使用中」は、今も使っていると資料から確かめられるものだけ
- 試作・見本・使わなかったものは「参考」、壊れた・役目を終えた・置き換わったものは「引退」
- 根拠がないものは推測で決めず、「要確認」の印を付けて聞く

## note
- 書く: 必要な部品（ねじ・磁石など）、対応する機種や型番、印刷のコツ、寸法を変えられる変数、
  作った経緯や使ってみた感想（作者の文はなるべく口調ごと残す）
- 書かない: 出どころの記録（元のパスや旧フォルダ名など）、purpose と同じ文の繰り返し
- 同じ系列の作品には、対応機種などの共通の情報をそろえて書く

## 進め方
1. 渡されたものを見て作品ごとにまとめる。どれが同じ作品か迷ったら聞く
2. 全作品の案（フォルダ名・purpose・status・tags・note）を表にし、推測した箇所と
   「要確認」に印を付けて、まとめて一度に確認をもらう。作成日などファイル名や
   更新日から推測できるものは案として示す
3. 確認が取れたらファイルを配置して meta.json を書く（UTF-8 で保存）。
   置き場所（共有ドライブの 3Dギャラリー/items/ のパス）が分からなければ聞く。
   まとめて書くときは、先に書き込まない試走で全件の変更内容を見せてから実行する。
   書き出し済みのフォルダの名前を変えたら、triage.csv の folder_name も同じ名前に直す
   （直さないと、書き出しの再実行で同じ作品がもう一度書き出される）
4. 書いたあとに全件を読み直して検査する（キーが仕様どおり、author・purpose・status が
   空でない、status が3択のどれか、tags と note が文字列の配列、フォルダ名の日付が実在する）
5. 最後に、フォルダ構成・各作品の status と tags・タグごとの件数を見せて、確認をもらう

## やらないこと
- モデルの形状やファイルの中身の変更
- 仕様にないキーやフォルダの追加

3フォルダにまとめて items/ に置く

フォルダ名は 作成日_名前（例：20250612_流路セルホルダー）。作成日がわからなければ大体でかまいません。中にはファイルを並べるだけで、サブフォルダは作りません。名前が _ で始まるフォルダ（_template など）は一覧に出ません。

手でやるフォルダを作って入れる

1・2 のファイルを入れたフォルダの名前を「作成日_名前」にして、items/ に置く。

Google ドライブ（パソコン版）ならエクスプローラーで普通に作業できます。Webの画面だけなら、items/ に新しいフォルダを作ってファイルをアップロードします。同じ名前のファイルがあれば「置き換える」を選んでください（2つあると要対応になります）。

自動でやる済んでいる

Fusionのスクリプト（モード2）は items/ に直接書き出します。AIエージェントに頼んだときは、確認のあとフォルダに並べてくれます。

4同期して確かめる

上の「今すぐ同期」を押すと一覧に出ます。出ないときは一覧の上に理由が表示されるので、その作品の meta.json を直してもう一度同期してください。
